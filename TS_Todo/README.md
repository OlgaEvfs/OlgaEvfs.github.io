# TS Kanban TODO

Simple **Kanban-style TODO board** built with **TypeScript**, using **localStorage** to persist tasks in the browser.

## Requirements

- Live Server (VS Code extension or other)

## Installation & Setup

**Clone the repository**  

git clone <your-repo-url>
cd ts-kanban-todo

## Open with Live Server

Open the project folder in VS Code.

Right-click index.html → Open with Live Server.

The app will open in your default browser.

## How to Use
Open the app in the browser via Live Server.

Add tasks to columns (To Do, In Progress, Testing, Done).

Drag and drop tasks between columns.

Tasks are saved in localStorage and persist after page reload.
