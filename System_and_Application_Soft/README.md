# System vs. Application Software

This is an interactive web application designed to help users learn and test their knowledge of the differences between system software and application software.

## ✨ Features

-   **Learning Mode:** Explore various types of software using interactive cards.
-   **Test Mode:** Challenge your knowledge by dragging and dropping software name cards into the correct categories.
-   **Interactive Interface:** A simple and intuitive drag-and-drop interface.
-   **Progress Tracking:** The application remembers which cards you have "learned."
-   **Instant Feedback:** Get immediate feedback on the correctness of your answers in test mode.

## 🛠️ Technologies

-   HTML5
-   CSS3
-   Vanilla JavaScript (ES6 Modules)
-   [Jest](https://jestjs.io/) for testing

## 🚀 Installation and Setup

1.  **Clone the repository:**
    ```bash
    git clone <repository-URL>
    cd <folder-name>
    ```

2.  **Install dependencies:**
    Node.js and npm are required to run tests. Install project dependencies with the command:
    ```bash
    npm install
    ```

3.  **Open in browser:**
    Simply open the `index.html` file in your favorite web browser to start using the application.

## 🧪 Running Tests

Tests written with Jest are used to verify the correct functioning of the application's logic. To run them, execute the command:

```bash
npm test
```

This will run the tests and display a code coverage report in the console.
